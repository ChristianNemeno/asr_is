# Datasets

Two datasets are available in this project. The **Filipino Speech Corpus + FLEURS** combination is used for training; the **Cebuano Speech Dataset** is available but not the primary training dataset.

---

## Primary Training Dataset: Filipino Speech Corpus + FLEURS

Used by `train/train_whisper.py` and `train/compare_models.py`.

### Filipino Speech Corpus (FSC)

- **Hugging Face**: `sapinsapin/filipinospeechcorpus`
- **Language**: Tagalog (Filipino)
- **Size**: ~50 hours
- **License**: MIT
- Preprocessing: filter samples with <2 words or <0.8s duration, normalize text (lowercase, strip punctuation)

### FLEURS

- **Hugging Face**: `google/fleurs`
- **Languages used**: `fil_ph` (Filipino/Tagalog), `ceb_ph` (Cebuano)
- **Size**: ~10 hours per language, ~20h total
- **License**: CC-BY 4.0

### Combined Splits

```python
# FSC: train → 90% train / 10% validation, keep original test
# FLEURS: keep original splits
# All concatenated per split
```

Generated by `load_datasets()` in `train/train_whisper.py:56-74`.

### Text Normalization

Both datasets use the same normalizer:

```python
def norm(text):
    t = text.lower()
    t = re.sub(r'[\,\?\.\!\-\;\:\"\“\%\‘\”\'\’\«\»\(\)\[\]]', '', t)
    return re.sub(r'\s+', ' ', t).strip()
```

## Secondary Dataset: Cebuano Speech Dataset

Used by `download.py` and referenced by the backend API. **Not used for Whisper training.**

### Source

- **Hugging Face**: `Speech-data/Cebuano-Speech-Dataset`
- **Website**: https://speech-data.ai/datasets/cebuano/
- **License**: CC BY-NC-ND 4.0

### Overview

| Property | Value |
|----------|-------|
| Total Audio | 108 hours |
| Number of Files | 807 |
| Total Size | ~135 MB |
| Formats | MP3, WAV |
| Language | Cebuano (Bisaya) |
| Gender Split | 49% Female / 51% Male |
| Age Range | 18 - 50+ years |
| Speaker Regions | Cebu, Mindanao, Bohol, Leyte (Philippines) |

### Loading

```python
from datasets import load_dataset, Audio

ds = load_dataset("Speech-data/Cebuano-Speech-Dataset")
ds = ds.cast_column("audio", Audio(sampling_rate=16000))
```

Expected columns: `AudioID`, `audio_text` (transcription), `gender`, `duration`, `format`, `audio`.

### Cebuano Language Notes

- Cebuano (Bisaya) is the second most spoken language in the Philippines (~21M speakers)
- Uses the Latin alphabet (A-Z, plus Ñ/ñ in formal writing)
- Word order is typically VSO (Verb-Subject-Object)
- Agglutinative language with complex verbal morphology

### Limitations

- Single dataset — no external validation source
- CC BY-NC-ND license restricts commercial use
- Speaker diversity limited to 4 Philippine regions
- Recording quality may vary across samples
